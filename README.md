# Andes to Copacabana

Interactive route planner for a Lima → Rio de Janeiro backpacking trip (Peru, Ecuador, Colombia, the Guianas, Brazil, Bolivia), ending on Copacabana for New Year's Eve.

Single HTML file, no backend. Photos are downscaled Wikimedia Commons images; the credits button in the app lists every file with author and licence.

- Desktop: map, photo pins, hostel cards, day-by-day itinerary, presets.
- Phone: opens as a read-only trip view of the route encoded in the link (`?r=...`), which "Send to phone" in the planner produces.
