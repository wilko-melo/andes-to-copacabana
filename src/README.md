# Source

Build: `python3 build6.py` inside this folder (needs Pillow only for image prep), then copy `andes-v6.html` to `../index.html` and bump the cache name in `../sw.js`.
Data lives in `data_*.js`; photos are Wikimedia Commons (see `credits.json`); `data_hw.js` holds Hostelworld links/photo URLs; `data_fixes.js` holds the research overlays.
